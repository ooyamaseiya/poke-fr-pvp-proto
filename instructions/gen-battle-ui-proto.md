# 指示書：ポケモン金銀風バトルUI（React + CSS）プロトタイプ実装

あなたはレトロゲーム（ゲームボーイカラー・ポケットモンスター金銀世代）のUI/UXデザイナー兼フロントエンドエンジニアです。
すでに生成済みのドット絵アセット（立ち絵・斬撃エフェクト）を読み込み、スマートフォン画面で遊べる**ポケモン金銀風のターン制バトルUI**を React + CSS で実装してください。

## 1. 使用する既存アセット

プロジェクト内の以下の画像アセットを使用します。
※Vite等の開発サーバーから読み込めるよう、必要に応じて `public/` ディレクトリへの配置（または適切な静的パス設定）を行ってください。

- **自分（プレイヤー側・背面）：** `output/assets/0383_back.png`（名前：`グラードン` / `72 × 72 px`）
- **相手（敵側・正面）：** `output/assets/0483_front.png`（名前：`ディアルガ` / `72 × 72 px`）
- **斬撃エフェクト：** `output/assets/effects/slash_sheet.png`（`320 × 64 px` / `64 × 64 px × 5フレーム` 横並びスプライトシート）

## 2. ビジュアル・スタイリング要件（金銀風の再現）

ゲームボーイカラー実機の雰囲気を忠実に再現するため、以下のCSSルールを厳守してください。

- **フォント：** Google Fonts から **`DotGothic16`** を読み込み、アプリ全体に適用すること。
- **ドット絵の鮮明化（必須）：** すべてのスプライト画像・エフェクト要素に `image-rendering: pixelated;` を適用し、拡大時にぼやけないようにすること。
- **カラーパレット制限：**
  - バトル画面背景：白〜ごく薄いクリーム色（`#F8F8F8`）
  - 文字・枠線：濃黒（`#181818`）
  - HPゲージ：残量50%超は緑（`#30B830`）、21〜50%は黄（`#F8C028`）、20%以下は赤（`#E83030`）
- **レトロウィンドウ枠：**
  - メッセージ枠・コマンド枠は、白背景＋太めの黒枠（`border: 4px solid #181818`）＋内側の影（`box-shadow`）や角の装飾で、金銀風の二重枠ウィンドウを再現すること。
- **レスポンシブ設計：**
  - スマホ縦画面（最大幅 `420px` 程度）を基準に中央配置し、画面内にバトルフィールドと操作パネルがスクロールなしで綺麗に収まるレイアウトにすること。

## 3. 画面レイアウト構成

画面を上下2セクション（上部：バトルフィールド、下部：ウィンドウ＆コマンド領域）で構成してください。

### 上部：バトルフィールド（比率 4:3 または 正方形に近いエリア）

1. **左上：相手ステータスボックス**
   - 名前（`ディアルガ`）、レベル（`Lv50`）
   - `HP` ラベルと、L字型の黒ラインで囲まれたHPバー（数値は非表示、バーのみ）
2. **右上：相手ポケモン表示エリア**
   - `0483_front.png` を2倍〜2.5倍程度（`144px`〜`180px`）に拡大表示。
   - この要素の真上に、**斬撃エフェクト再生用のオーバーレイレイヤー**を配置すること。
3. **左下：自分ポケモン表示エリア**
   - `0383_back.png` を2倍〜2.5倍程度に拡大し、バトルフィールドの**下辺にぴったり接地**させて配置すること。
   - 相手からの攻撃時にエフェクトを重ねられるよう、こちらにもエフェクトレイヤーを用意すること。
4. **右下：自分ステータスボックス**
   - 名前（`グラードン`）、レベル（`Lv50`）
   - HPバー ＋ **現在HP / 最大HP の数値表示**（例：`180 / 180`）

### 下部：メッセージ＆コマンド領域

- **メッセージウィンドウ：**
  - 戦闘テキストを**1文字ずつ表示するタイプライター演出**（約35ms/文字）を実装すること。
- **コマンドウィンドウ：**
  - 待機状態では右下に「▶ たたかう」「　 リセット」などの2択メニューを表示。
  - 「たたかう」を押すと、技選択ウィンドウ（例：`きりさく`、`だんがいのつるぎ` 等）に切り替わり、技を選ぶと攻撃フェーズへ進む。
  - 選択中の項目には黒い右向き三角カーソル（`▶`）を表示すること。

## 4. アニメーション実装要件（CSS `steps()` 活用）

Reactのフレーム更新（`setInterval` 等）でアニメーションさせず、**CSSアニメーション**で軽快に実装してください。

1. **斬撃エフェクト再生（`slash_sheet.png`）：**
   - `background-image` に `slash_sheet.png` を設定し、`background-size: 500% 100%;` にする。
   - `@keyframes` で `background-position` を `0%` から `-500%` へ動かし、`animation: slash-play 0.35s steps(5) forwards;` で5コマをカクカク再生する。
   - 相手の攻撃時は、同じエフェクトを `transform: scaleX(-1);` で左右反転させて自分側（左下）に再生する。
2. **ヒット演出（Frame 3のタイミング・開始から約140ms後）：**
   - ダメージを受けた側の立ち絵を、金銀特有の**「点滅（`opacity: 0` と `1` を `steps(2)` で高速切り替え）」＋「小刻みな横揺れ」**で約0.4秒間アニメーションさせる。
   - バトルフィールド全体を一瞬（約80ms）白くフラッシュさせる。
3. **HPバーの減少：**
   - `transition: width 0.5s linear;` で滑らかに減少させ、減少途中で50%・20%を切ったら色が切り替わるようにする。

## 5. バトル進行ステートマシン（動作確認用ロジック）

UIの見た目だけでなく、実際にタップして一連のバトル演出をテストできるように以下の状態遷移を実装してください。

- **初期ステータス（テスト用）：**
  - グラードン：HP `180/180`、技1「きりさく（威力高め・斬撃エフェクト）」、技2「れんぞくぎり（斬撃エフェクトを左右反転で2連続再生）」
  - ディアルガ：HP `180/180`、技「メタルクロー（斬撃エフェクト）」
- **ターン進行フロー：**
  1. `MENU`：「グラードンは どうする？」→ プレイヤーが技を選択
  2. `PLAYER_TURN`：「グラードンの きりさく！」→ 斬撃エフェクト再生 → ヒット演出 → ディアルガのHP減少
  3. 勝敗判定（相手HPが0なら `VICTORY` へ、立ち絵が下に沈んで消える演出）
  4. `ENEMY_TURN`：「あいての ディアルガの メタルクロー！」→ 自分側で斬撃エフェクト再生 → ヒット演出 → グラードンのHP減少
  5. 勝敗判定（自分HPが0なら `DEFEAT` へ、そうでなければ `MENU` へ戻る）
  6. 決着後は「もういちど たたかう」ボタンでHPを全回復してリスタート可能にする。

## 6. 実行・納品手順

1. 既存のReactプロジェクト構造を確認し、必要なコンポーネントとCSSファイル（例：`src/App.jsx`, `src/BattleScreen.css` 等）を作成する。
2. アセット画像（`0383_back.png`, `0483_front.png`, `slash_sheet.png`）がブラウザから404にならず正しく読み込まれるようパスを解決・配置する。
3. 開発サーバーを起動し、エラーなくビルド・表示できることを確認して完了報告を行う。
