# 指示書：Step 2-3 攻撃実行・ダメージ計算・クールタイムの実装

あなたはレトロゲーム（ゲームボーイカラー・ポケットモンスター金銀世代）のフロントエンドエンジニアです。
Step 2-2で実装した「P1選択 → 目隠し画面 → P2選択」の流れに続けて、**「すばやさ順の全体攻撃」「ダメージ計算とHP減少」「クールタイム（おやすみ状態）」**のバトルロジックを `BattleScreen.jsx` / `BattleScreen.css` に実装してください。

※重要（スコープ制限）：
今回は**「先発3体同士での攻撃・ダメージ・クールタイムのループ」のみ**を実装します。
以下の要素は**まだ実装しないでください**（次のステップで実装します）：

- 控え（残り3体）からの交代処理
- 6ターン終了時の勝敗判定・リザルト画面
- 斬撃エフェクト再生、立ち絵の点滅・揺れ、タイプライター文字送り

## 1. バトル用フィールド状態（State）の拡張

Part 1から受け取った `p1Team` / `p2Team` の先頭3体（`slice(0, 3)`）を、バトル中に更新できるState（`p1Field`, `p2Field`）として初期化してください。各ポケモンに以下のプロパティを持たせます。

```javascript
// フィールド上の1体あたりのデータ構造
{
  ...pokemonData,        // id, name, maxHp, atk, def, spd, moveName, sprites 等
  currentHp: pokemonData.maxHp,
  isFainted: false,      // HPが0になったら true
  cooldown: false        // 前のターンに攻撃したら true（おやすみ中）
}
```

## 2. ダメージ計算式とHPバーの連動

- **ダメージ計算式：**
  ```javascript
  const base = Math.floor(attacker.atk * 0.65 - defender.def * 0.25);
  const variance = 0.9 + Math.random() * 0.2; // 0.9〜1.1倍
  const damage = Math.max(15, Math.floor(base * variance)); // 最低保証15ダメージ
  ```
- **全体攻撃：** 攻撃者の攻撃は、**相手の場にいる生存ポケモン（`!isFainted`）全員**にそれぞれダメージ計算して適用する。
- **HPバーのアニメーションと色変化：**
  - HPバーの `width` に `transition: width 0.5s linear;` を設定し、ダメージ時に滑らかに減るようにする。
  - 残りHP割合（`currentHp / maxHp`）に応じて色を動的に切り替える：
    - `50%超`：緑（`#30B830`）
    - `21%〜50%`：黄（`#F8C028`）
    - `20%以下`：赤（`#E83030`）
- **戦闘不能（`currentHp === 0`）の表示：**
  - `isFainted = true` とし、バトルフィールド上の立ち絵をグレースケール＋半透明（`opacity: 0.3; filter: grayscale(100%);`）にして倒れたことが分かるようにする。

## 3. 攻撃実行シーケンス（`BATTLE_EXECUTING` フェーズ）

Step 2-2の仮フェーズ `CONFIRM_SELECTION` を置き換え、P2がポケモンを選んだ直後に `turnPhase` を `'BATTLE_EXECUTING'` にして、以下の順番で自動進行（`async/await` と約 `1200ms` のウェイト関数を使用）させてください。

1. **先攻・後攻の決定：**
   - P1が選んだポケモンとP2が選んだポケモンの `spd` を比較し、大きい方を先攻にする（同値の場合はランダム）。
   - メッセージ表示：`[先攻のポケモン名] のほうが はやい！`（ウェイト）
2. **先攻の攻撃実行：**
   - メッセージ表示：`[P1/P2] の [先攻ポケモン名] の [技名]！`（ウェイト）
   - 相手フィールドの生存ポケモン全員にダメージを与え、HPを更新する。
   - メッセージ表示：`あいての ポケモンたちに ダメージ！`（ウェイト）
3. **後攻の攻撃実行（キャンセル判定あり）：**
   - 先攻の攻撃で、後攻が選んだ攻撃役がすでに戦闘不能（`currentHp <= 0`）になっているかチェックする。
   - **倒れている場合：**
     - メッセージ表示：`[後攻ポケモン名] は たおれて こうげきできない！`（ウェイト）
     - 後攻の攻撃はキャンセルする。
   - **生きている場合：**
     - 先攻と同様に技名表示 → 相手フィールド全員へダメージ適用 → メッセージ表示（ウェイト）。
4. **クールタイム（おやすみ状態）の更新：**
   - まず、前のターンに `cooldown: true` だった全ポケモンのクールタイムを `false` に解除する。
   - 次に、**このターンに実際に攻撃を実行したポケモン**（キャンセルされず攻撃した個体）に `cooldown: true` を設定する。
   - **詰み防止ルール（重要）：** もし「生存しているポケモン全員が `cooldown: true`」になってしまう場合（例：生存が残り1体だけの時）、そのプレイヤー側の全ポケモンの `cooldown` を強制的に `false` にリセットする。
5. **次のターンへ戻る：**
   - 選択状態（`p1SelectedIndex`, `p2SelectedIndex`）を `null` にリセットし、`turn` 数を `+1` して `turnPhase` を `'SELECT_P1'` に戻す。
   - ※Step 2-3のテスト中にどちらかの先発3体が全滅した場合は、クラッシュしないようメッセージに `テストしゅうりょう！ リセットしてね` と表示し、コマンド欄に「リセット」ボタンを出すこと。

## 4. 選択画面（`SELECT_P1` / `SELECT_P2`）のボタン制御

- **`cooldown: true` のポケモン：**
  - ボタンを `disabled`（選択不可）にし、グレーアウト表示＋`💤 おやすみ` のバッジを表示する。
  - バトルフィールド上の立ち絵付近にも小さく `💤` を表示すると分かりやすい。
- **`isFainted: true` のポケモン：**
  - ボタンを `disabled`（選択不可）にし、`ひんし` と表示する。
- **`BATTLE_EXECUTING` 中：**
  - コマンドパネルのボタンはすべて非表示または操作ロックにする。

## 5. 実行・確認手順

1. `src/BattleScreen.jsx` および `src/BattleScreen.css` を更新する。
2. ビルド・起動し、以下の挙動をすべて確認して完了報告を行うこと。
   - `spd` が高い方から先に攻撃し、相手3体のHPバーが滑らかに減って色が変わること。
   - 先攻の攻撃で後攻の選択ポケモンが倒れた場合、後攻の攻撃がキャンセルされること。
   - 次のターンで、直前に攻撃したポケモンが `💤 おやすみ` になり選択できないこと（残り1体になった時は例外的に選択できること）。
   - 複数ターン連続してエラーなくバトルがループすること。
