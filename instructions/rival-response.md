# 指示書：Step 2-2 バトル画面「P1選択 → 目隠し画面 → P2選択」の画面遷移実装

あなたはレトロゲーム（ゲームボーイカラー・ポケットモンスター金銀世代）のUI/UXデザイナー兼フロントエンドエンジニアです。
Step 2-1で作成した3vs3バトルUI（`BattleScreen.jsx` / `BattleScreen.css`）に、**「P1選択 → 目隠し画面 → P2選択 → 選択結果の確認」というブラインド選択の画面遷移**を実装してください。

※重要（スコープ制限）：
今回は**「お互いが攻撃ポケモンを選び終えるまでの画面遷移」のみ**を実装します。
ダメージ計算、HPバーの減少、クールタイム（おやすみ）、控えからの交代、斬撃エフェクト、勝敗判定は**まだ実装しないでください**。

## 1. 追加する状態（State）の設計

`BattleScreen.jsx` 内に以下のStateを追加してください。

- `turnPhase`：現在の選択フェーズを管理する文字列
  1. `'SELECT_P1'`（初期値：P1が攻撃ポケモンを選ぶ）
  2. `'HANDOVER_TO_P2'`（目隠し画面：P1の選択を隠してP2へスマホを渡す）
  3. `'SELECT_P2'`（P2が攻撃ポケモンを選ぶ）
  4. `'CONFIRM_SELECTION'`（Step 2-2の動作確認用：両者の選択を公開して確認する仮フェーズ）
- `p1SelectedIndex`：P1が選んだポケモンのインデックス（`0` | `1` | `2` | `null`）
- `p2SelectedIndex`：P2が選んだポケモンのインデックス（`0` | `1` | `2` | `null`）

## 2. 各フェーズのUIと挙動

### ① `SELECT_P1`（P1の選択）

- **メッセージウィンドウ：** `P1の ターン！ こうげきする ポケモンを えらんでね！`
- **コマンドパネル：**
  - P1の先発3体（`p1Team.slice(0, 3)`）の選択ボタンを表示する。
  - P1のターンであることが子供にも直感的に分かるよう、パネル枠やラベルにP1カラー（青 `#2860D8`）のアクセントをつける。
- **ボタン押下時：**
  - `p1SelectedIndex` に選んだインデックスを保存し、即座に `turnPhase` を `'HANDOVER_TO_P2'` へ切り替える。

### ② `HANDOVER_TO_P2`（目隠し画面）

- **レイアウト：** バトルフィールド全体を覆うフルスクリーン（または画面中央の大きなレトロウィンドウ）のオーバーレイを表示し、P1が何を選んだか見えないようにする。
- **表示内容：**
  - タイトル：`P2に スマホを わたしてね！`
  - 補足テキスト：`P1の せんたくは かくされているよ`
  - 決定ボタン：`P2 じゅんび OK！`（P2カラーの赤 `#D82828` をアクセントに使用）
- **ボタン押下時：**
  - `turnPhase` を `'SELECT_P2'` へ切り替える。

### ③ `SELECT_P2`（P2の選択）

- **メッセージウィンドウ：** `P2の ターン！ こうげきする ポケモンを えらんでね！`
- **コマンドパネル：**
  - **P2の先発3体（`p2Team.slice(0, 3)`）**の選択ボタンに切り替えて表示する。
  - P2のターンであることが分かるよう、パネル枠やラベルにP2カラー（赤 `#D82828`）のアクセントをつける。
- **ボタン押下時：**
  - `p2SelectedIndex` に選んだインデックスを保存し、`turnPhase` を `'CONFIRM_SELECTION'` へ切り替える。

### ④ `CONFIRM_SELECTION`（動作確認用の仮公開フェーズ）

- **バトルフィールド：**
  - P1側・P2側それぞれで選ばれたポケモンの立ち絵（またはステータス枠）に、選択中であることが分かる強調枠（ハイライト）をつける。
- **メッセージウィンドウ：**
  - `P1は [P1ポケモン名]！ P2は [P2ポケモン名]を えらんだ！` と表示する。
- **コマンドパネル：**
  - 次のステップへ進む前のテスト用として、`もういちど えらぶ（リセット）` ボタンを1つ表示する。
  - 押すと `p1SelectedIndex` / `p2SelectedIndex` を `null` に戻し、`turnPhase` を `'SELECT_P1'` に戻す。

## 3. 実行・確認手順

1. `src/BattleScreen.jsx` および `src/BattleScreen.css` を更新する。
2. ビルド・起動し、以下の流れがスマホ幅（約375px〜420px）で崩れずに動作することを確認して完了報告を行う。
   - `SELECT_P1` でP1の3体が表示され、1体選ぶと目隠し画面に切り替わること。
   - 目隠し画面の「P2 じゅんび OK！」を押すと、`SELECT_P2` に移りコマンドパネルがP2の3体に切り替わること。
   - P2が1体選ぶと、両者の選択結果がメッセージとハイライトで正しく表示され、リセットボタンで最初から繰り返せること。
