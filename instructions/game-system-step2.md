# 指示書：ステップA（Part 2）3vs3金銀風PvPバトルエンジンの実装

Part 1で実装した `ENTRY_P1` / `ENTRY_P2` から渡される「P1・P2それぞれの6体データ（先発3体＋控え3体）」を受け取り、**ポケモンフレンダ風ルール × 金銀風グラフィック**の本格的なPvPバトル画面（`BattleScreen.jsx`）を実装してください。

## 1. バトル基本ルール（厳守）

- **ターン制：** 最大 **6ターン** で決着。
- **場の構成：** お互いに **場（先発）3体**、**控え 3体**。
- **ブラインド選択（目隠し）：**
  1. P1が場の3体から攻撃する1体を選ぶ。
  2. **目隠し画面（「P2に スマホを わたしてね！」＋「じゅんびOK」ボタン）**を表示し、P1の選択を隠す。
  3. P2が場の3体から攻撃する1体を選ぶ。
- **クールタイム制（おやすみ状態）：**
  - 攻撃を実行したポケモンは「おやすみ（`cooldown: true`）」状態になり、**次の1ターンは選択不可**（グレーアウト＋`💤`アイコン表示）。
  - ※場の生存ポケモン全員がおやすみ状態になるのを防ぐため、生存が1体だけになった場合は例外的にクールタイムを解除すること。
- **すばやさ順の全体攻撃：**
  - P1とP2が選んだ攻撃役の `spd`（すばやさ段階）を比較し、大きい方が先攻（同値ならランダム）。
  - 攻撃は**相手の場にいる生存ポケモン全員（最大3体）への全体攻撃**とする。
  - **重要：** 先攻の攻撃で、後攻が選んだ攻撃役が戦闘不能（HP 0）になった場合、**後攻の攻撃はキャンセル（不発）**になる。
- **自動補充（交代）：**
  - ターン終了時（または戦闘不能発生時）、控えに生存ポケモンがいれば空いた枠へ**自動的に補充**する（「控えから 〇〇が とびだした！」とメッセージ表示）。
- **勝敗判定：**
  - 6ターン終了時、またはどちらかの6体すべてが戦闘不能になった時点で終了。
  - **判定基準：** ①「相手を倒した数」が多い方の勝ち → ②同点なら「場と控えに残っているポケモンの残りHP合計」が多い方の勝ち → ③それでも同じなら引き分け。

## 2. ダメージ計算式（シンプル＆爽快バランス）

6ターン以内に適度にポケモンが倒れるよう、以下の計算式をベースに調整してください。

- `基本ダメージ = Math.floor((攻撃側のatk * 0.65) - (防御側のdef * 0.25))`
- 最低保証ダメージは `15` とし、ランダム乱数（`0.9 〜 1.1`倍）を掛ける。

## 3. 金銀風 3vs3 バトルUIレイアウト（スマホ縦画面 `max-width: 420px`）

スクロールなしで1画面に収まるよう、以下の3段構成にしてください。

1. **上部：バトルフィールド（背景 `#F8F8F8`）**
   - **上段（相手・P2側）：** 3体のポケモン（`front` 画像）を横並び表示。各ポケモンの上または下にコンパクトな「名前・HPバー（緑/黄/赤）」を表示。
   - **下段（自分・P1側）：** 3体のポケモン（`back` 画像）を横並び表示。各ポケモンの下に「名前・HPバー・HP数値」を表示。
   - **ターン＆スコアヘッダー：** 画面最上部に `TURN 1/6` と `P1倒した数 vs P2倒した数` をレトロ枠で表示。
   - **エフェクトオーバーレイ：** 攻撃を受けた側（3体全体または各個体）の上に、`output/assets/effects/slash_sheet.png`（5コマ）をCSSの `animation: steps(5)` で再生する。ヒット時に立ち絵を点滅＋横揺れさせる。
2. **中部：メッセージウィンドウ**
   - 金銀風の二重黒枠ウィンドウ。タイプライター演出（約30ms/文字）で実況テキストを表示。
3. **下部：コマンド・選択パネル**
   - 選択フェーズ（`SELECT_P1` / `SELECT_P2`）では、場の3体に対応した大きなタップボタンを表示（技名・すばやさ `▲`・おやすみ中なら選択不可表示）。
   - 演出中（`ANIMATING`）は操作をロックする。

## 4. 演出シーケンス（状態遷移）

非同期処理（`async/await` とウェイト関数）を使い、以下のテンポで進行させてください。

1. `SELECT_P1` → `HANDOVER`（目隠し）→ `SELECT_P2`
2. `EXEC_FIRST_ATTACK`：先攻の技名表示 → 斬撃エフェクト再生 → 相手3体ダメージ＆HPバー減少 → 戦闘不能チェック
3. `EXEC_SECOND_ATTACK`：後攻の攻撃役が生きていれば同様に実行（倒れていれば「〇〇は たおれて こうげきできない！」と表示）
4. `REFILL`：倒れた枠があれば控えから自動補充
5. `TURN_END`：クールタイム更新、ターン数+1。終了条件を満たせば `RESULT`（勝敗・倒した数・残りHP合計を表示＋「もういちど あそぶ」ボタン）へ遷移。

## 5. 実行・確認手順

1. `BattleScreen.jsx` と専用の `BattleScreen.css` を作成し、`App.jsx` の `BATTLE` フェーズに組み込む。
2. エントリー画面から6体ずつ選び、6ターン最後まで（または全滅まで）エラーなく進行し、目隠し画面・クールタイム・全体攻撃エフェクト・自動補充・勝敗判定がすべて正しく動作することを確認して報告する。
