# 指示書：Step 2-1 バトル画面のUIレイアウト実装（見た目のみ）

あなたはレトロゲーム（ゲームボーイカラー・ポケットモンスター金銀世代）のUI/UXデザイナー兼フロントエンドエンジニアです。
すでに実装済みのエントリー画面（Part 1）から受け取った「P1の先発3体」「P2の先発3体」のデータを使い、**3体 vs 3体が向かい合うポケモン金銀風のバトル画面UI（`BattleScreen.jsx` / `BattleScreen.css`）**を作成してください。

※重要（スコープ制限）：
今回は**「UIの見た目とレイアウト」のみ**を実装します。
攻撃ロジック、ダメージ計算、ターン遷移、目隠し画面、斬撃エフェクト、タイプライター演出は**まだ実装しないでください**（ダミーの表示や見た目だけのボタンで構いません）。

## 1. デザイン・スタイル要件（金銀風）

- **フォント：** `DotGothic16` を適用。
- **ドット絵設定：** すべての立ち絵に `image-rendering: pixelated;` を適用し、拡大してもぼやけないようにする。
- **カラーパレット：**
  - バトルフィールド背景：`#F8F8F8`
  - 文字・枠線：`#181818`
  - HPバー（満タン時）：緑 `#30B830`
- **レトロウィンドウ枠：** 白背景＋太めの黒枠（`border: 4px solid #181818;`）＋内側の影で金銀風の二重枠を再現する。
- **1画面完結（スマホ縦画面最適化）：**
  - 最大幅 `420px`、高さ `100dvh`（または `100vh`）の中に、**縦スクロールなしで全要素が収まる**ように `display: flex; flex-direction: column;` で高さを配分する。

## 2. 画面レイアウト構成（上から順に4セクション）

### ① ヘッダーバー（高さ目安：約 36〜44px）

- 左側：`TURN 1/6`
- 右側：`P1 0 - 0 P2`（倒した数スコアの枠）＋ 小さな「もどる」ボタン（タイトル画面へ戻るテスト用）

### ② バトルフィールド（画面のメイン領域：`flex: 1`）

P2（相手）の3体と、P1（自分）の3体が**上下に向かい合う（対面する）構図**で配置する。

- **上段：相手（P2）エリア（3体横並び・3カラム均等配置）**
  - `grid-template-columns: repeat(3, 1fr);` でP2の先発3体を横に並べる。
  - 各ポケモンのカード構成（上から順）：
    1. コンパクトなステータス枠（名前・HPバーのみ。文字がはみ出さないよう小さく調整）
    2. 相手の立ち絵（`front` 画像。幅 `80px〜96px` 程度でくっきり表示）
- **中央の余白（対戦の距離感）：**
  - 上段と下段の間に適度なスペースを設け、向き合っている感覚を出す（うっすらと中央線や影を置いても良い）。
- **下段：自分（P1）エリア（3体横並び・3カラム均等配置）**
  - `grid-template-columns: repeat(3, 1fr);` でP1の先発3体を横に並べる。
  - 各ポケモンのカード構成（上から順）：
    1. 自分の立ち絵（`back` 画像。幅 `88px〜104px` 程度で、相手よりやや手前に大きく見せる）
    2. コンパクトなステータス枠（名前・HPバー・`180/180` のような現在HP/最大HP数値）

### ③ メッセージウィンドウ（高さ目安：約 72〜84px）

- 金銀風の二重黒枠ウィンドウ。
- 現段階では固定のダミーテキスト（例：`P1の ターン！ こうげきする ポケモンを えらんでね！`）を表示する。

### ④ コマンド・選択パネル（高さ目安：約 130〜150px）

- 下部に配置する操作パネル。P1の先発3体に対応する**3つの選択ボタン**を横並び（または縦3行のリスト形式）で配置する。
- 各ボタン内に表示する情報（見た目確認用）：
  - ポケモン名
  - 技名（例：`だんがいのつるぎ`）
  - すばやさ表示（例：`▲▲▲`）
- ※今回はボタンをタップしてもバトルは進まず、押したボタンの枠が強調される（または `console.log` に名前が出る）程度の仮動作でOK。

## 3. データの受け取りとフォールバック

- `App.jsx` の `BATTLE` フェーズから、P1・P2それぞれが選んだ6体の配列（`p1Team`, `p2Team`）を受け取り、先頭3体（`slice(0, 3)`）を表示する。
- もし開発中にデータが未定義だった場合でも画面がクラッシュしないよう、デフォルトのダミーデータをフォールバックとして持たせておくこと。

## 4. 実行・確認手順

1. `src/BattleScreen.jsx` と `src/BattleScreen.css` を作成し、`App.jsx` に接続する。
2. ビルド・起動し、スマホ幅（約375px〜420px）のブラウザ表示で以下を確認して完了報告を行う。
   - P1とP2の先発3体ずつが崩れずに横3列で向かい合って表示されていること。
   - 名前やHPバーが重なったり、画面外にはみ出したりしていないこと。
   - 縦スクロールなしで1画面に綺麗に収まっていること。
