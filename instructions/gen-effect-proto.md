# 指示書：ポケモン金銀風「斬撃（Slash）」エフェクト画像 自動生成パイプライン

あなたはレトロゲーム（ゲームボーイカラー・ポケットモンスター金銀世代）のドット絵テクニカルアーティスト兼Pythonエンジニアです。
スマホ向けWeb PvPバトルゲームで使用する**「斬撃」エフェクトの5コマアニメーション画像（透過PNGスプライトシート）**を、Pythonスクリプトを用いて生成してください。

※注意：SVG形式での出力は禁止します。必ずPython（`Pillow`, `numpy`）を用いてピクセル単位で描画し、PNG画像として保存してください。

## 1. 基本スペックとカラーパレット

ゲームボーイカラー実機のようなキレのあるドット絵にするため、以下の仕様を厳守してください。

- **1フレームの解像度：** `64 × 64 ピクセル`
- **フレーム数：** `5フレーム`（横並び結合）
- **スプライトシート出力サイズ：** `320 × 64 ピクセル`（透過PNG / RGBA）
- **アンチエイリアス：** 禁止（すべてのピクセルのAlphaは `0` または `255` の完全二値とし、エッジをくっきりさせること）
- **カラーパレット（透過 ＋ 3色厳守）：**
  - 透過：`(0, 0, 0, 0)`
  - 白（芯・ハイライト）：`#FFFFFF`
  - 薄グレー（中間色・残像）：`#A8A8A8`
  - 黒（外周1pxの輪郭線）：`#101010`

## 2. 5フレームの詳細設計図（描画アルゴリズム要件）

各フレームは `64 × 64` のキャンバス内に以下の構成で描画してください。
※斬撃ラインは単なる等幅の直線ではなく、**中央に向かって太くなり両端が鋭く尖る紡錘形（または緩やかな弧）**を数式（ベジェ曲線や距離関数など）で計算して描画すること。

- **Frame 1（0〜63px：切り始め）**
  - 右上 `(54, 10)` から中央 `(32, 32)` に向けて、細い斜め線がスッと入る。
  - 線の最大幅は `2〜3px` 程度（白の芯＋外周1pxの黒フチ）。
- **Frame 2（64〜127px：振り抜き）**
  - 右上 `(58, 6)` から左下 `(6, 58)` へ一気に貫通する鋭い斬撃。
  - 中央付近の最大幅を `7〜9px` 程度にし、両端は `1px` に向かってシャープに尖らせる。
  - 内側を白、その外側に1pxの薄グレー、さらに最外周1pxを黒で縁取る。
- **Frame 3（128〜191px：最大発光・インパクト）**
  - Frame 2の貫通ラインをやや細めつつ白の面積を強調し、斬撃ラインの周囲に**「火花ドット」**を8〜12個ほど散らす。
  - 火花ドットは `2×2px` の点や `3×3px` の小さな十字型（中心が白、周囲が黒または薄グレー）で表現し、斬撃の軌道から外側へ飛び散る配置にする。
- **Frame 4（192〜255px：減衰・途切れ）**
  - 斬撃の主線が `2〜3px` 程度に細くなり、線の途中に透過の切れ目を入れて「破線状」に消えかけている表現にする。
  - 色は白を減らし、薄グレーと黒を主体にする。
  - Frame 3の火花ドットを少し外側へ移動させる。
- **Frame 5（256〜319px：余韻・消滅）**
  - 斬撃の主線は完全に消去する。
  - 外側へ飛び散った小さなドット粒子（`1〜2px` の白・薄グレー・黒）を6〜8個だけ残して余韻を演出する。

## 3. 出力ファイル要件

スクリプト `build_slash_effect.py` を作成・実行し、以下のファイルを `./output/assets/effects/` に保存してください。

1. **ゲーム実装用スプライトシート（必須）：**
   - `./output/assets/effects/slash_sheet.png`（`320 × 64 px`、透過PNG）
2. **人間確認用プレビューGIF（必須）：**
   - `./output/assets/effects/slash_preview.gif`
   - 視認性確認のため、背景を濃いグレー（`#282828`）にして `4倍拡大（256 × 256 px、ニアレストネイバー法）` し、1フレーム `70ms`（計0.35秒）＋末尾に `300ms` のウェイトを入れてループ再生するGIFを生成すること。

## 4. 実行順序

1. `build_slash_effect.py` を作成して実行する。
2. 生成された `slash_sheet.png` の画像サイズ（`320x64`）、使用色数（透過含め4色以内）、半透明ピクセルが0個であることをスクリプト内で自動検証し、結果をログ出力する。
3. 検証が通ったら完了報告を行う。
