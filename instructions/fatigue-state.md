# 指示書：Step 2-3c 攻撃後の「2ターン疲労状態（💦）」の実装

あなたはレトロゲーム（ゲームボーイカラー・ポケットモンスター金銀世代）のフロントエンドエンジニアです。
Step 2-3bで実装した「ダメージ計算とHPバー更新」に続けて、同じポケモンの連続使用を防ぐための**「2ターン疲労状態（クールタイム）」と、視覚的な `💦` マーク表示**を `BattleScreen.jsx` / `BattleScreen.css` に実装してください。

※重要（スコープ制限）：
今回は**「疲労ステートの管理・選択制限・`💦`マーク表示」のみ**を実装します。
控え（残り3体）からの交代処理、6ターン勝敗判定、斬撃エフェクトは**まだ実装しないでください**。

## 1. フィールド上のポケモンStateの拡張

`p1Field` / `p2Field` の各ポケモンオブジェクトに、疲労の残りターン数を表す数値プロパティ `fatigueTurns` を追加してください。

```javascript
// フィールド上の1体あたりのデータ構造
{
  ...pokemonData,
  currentHp: pokemonData.maxHp,
  isFainted: false,
  fatigueTurns: 0 // 0 = 元気（選択可能）、1〜2 = 疲労状態（選択不可）
}
```

## 2. 疲労状態の更新ルール（ターン終了時）

1ターンの攻撃処理（先攻・後攻の攻撃）がすべて完了し、次のターン（`SELECT_P1`）へ戻る直前に、以下の順序で `p1Field` と `p2Field` の `fatigueTurns` を更新してください。

1. **既存の疲労カウントを減らす：**
   - このターンに攻撃を実行していないポケモンについて、`fatigueTurns > 0` であれば `fatigueTurns - 1`（下限 `0`）にする。
2. **攻撃したポケモンに疲労を付与する：**
   - このターンに**実際に攻撃を実行したポケモン**（先攻の攻撃で倒れてキャンセルされた場合は除く）の `fatigueTurns` を **`2`** にセットする。
   - ※これにより、「Turn 1で攻撃 → Turn 2は疲労(2) → Turn 3は疲労(1) → Turn 4で回復(0)」となり、攻撃後ちょうど2ターン使用不可になります。
3. **詰み防止ルール（超重要）：**
   - 2ターン疲労制では、生存ポケモンが2体以下になった際に全員が疲労状態になり誰も選べなくなる（詰む）ことがあります。
   - これを防ぐため、P1側・P2側それぞれについて**「生存しているポケモン（`!isFainted`）が1体以上いるのに、生存ポケモン全員が `fatigueTurns > 0` である」**場合、生存ポケモンの中で最小の `fatigueTurns` の値（`minFatigue`）を求め、生存ポケモン全員の `fatigueTurns` から `minFatigue` を差し引くこと（最も回復が近いポケモンが `0` になり選択可能になる）。

## 3. 視覚的表現（UI要件）

### ① バトルフィールド（立ち絵の左上）

- `fatigueTurns > 0` かつ `!isFainted` のポケモンの立ち絵コンテナ（`position: relative;`）の**左上**に、`💦` マークをオーバーレイ表示する。
  - CSS配置例：`position: absolute; top: 2px; left: 2px; z-index: 10;`
  - 視認性を高めるため、白背景や黒縁の小さなバッジ（または白い影付き）にして、立ち絵と重なってもはっきり見えるようにすること。
  - `💦` の横に小さく残りターン数（例：`💦2` / `💦1`）を併記しても良い。
- 疲労中の立ち絵は少しだけ明度を落とす（例：`filter: brightness(0.85);`）などして、元気なポケモンと一目で区別できるようにする。

### ② 選択パネル（`SELECT_P1` / `SELECT_P2`）

- `fatigueTurns > 0` のポケモンボタンは **`disabled`（選択不可）** にする。
- ボタンをグレーアウト表示にし、テキストまたはバッジで **`💦 ひろう（あと2ターン）`** / **`💦 ひろう（あと1ターン）`** のように残りターン数が分かる表示をつける。
- ※`isFainted: true` の場合はこれまで通り `ひんし` 表示を優先すること。

### ③ テスト用リセットボタンの連動

- 既存の「HPリセット」ボタンを押した際、全員の `fatigueTurns` も `0` に初期化されるようにすること。

## 4. 実行・確認手順

1. `src/BattleScreen.jsx` および `src/BattleScreen.css` を更新する。
2. ビルド・起動し、以下の動作をすべて確認して完了報告を行うこと。
   - Turn 1で攻撃したポケモンに、Turn 2開始時から立ち絵の左上に `💦` マークがつき、選択ボタンが `disabled` になること。
   - Turn 2で別のポケモンが攻撃した後、Turn 1のポケモンはまだ疲労中（あと1ターン）で選べず、Turn 3で3体目のポケモンを使う必要があること。
   - Turn 4になったタイミングで、Turn 1のポケモンの `💦` マークが消えて再び選択可能になること。
   - 1体以上が戦闘不能になり生存が2体以下になっても、詰み防止ルールが働いて必ず最低1体は選択できること。
